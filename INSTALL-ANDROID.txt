УСТАНОВКА НА ANDROID (Яндекс.Браузер) — сборка БЕЗ ПОДПАПОК

В этой папке НЕТ ни одной вложенной папки. Все файлы лежат в один уровень,
иконки тоже: icon16.png, icon32.png, icon48.png, icon128.png.
Именно поэтому здесь нет ошибок вида:
  «Не удается загрузить javascript «src/core/stats.js»...»
  «Could not load icon 'icons/16.png' specified in 'icons'»

ПОРЯДОК ДЕЙСТВИЙ

1. Распакуй архив в отдельную папку, например:
       /storage/emulated/0/Download/IdleArcAndroid/

2. Открой эту папку файловым менеджером и убедись, что видишь СРАЗУ:
       manifest.json
       popup.html
       stats.js
       icon16.png ... icon128.png
   Никаких вложенных папок быть не должно.

   Частая беда: архиватор создаёт ДВОЙНУЮ папку —
       IdleArcAndroid/idlearc-analyst-android/manifest.json
   Если так получилось, перенеси файлы из внутренней папки наружу
   или просто запомни правильный путь.

3. Удали мусор, если появился: _metadata, __MACOSX, .DS_Store.

4. Храни папку во внутренней памяти (Download/Documents).
   Не в корне SD-карты и не в облачных разделах — SAF их читает нестабильно.

5. browser://extensions → включи «Режим разработчика» →
   «Загрузить распакованное расширение».

6. В системном выборе файлов зайди в папку IdleArcAndroid и выбери ФАЙЛ
   manifest.json (на Android выбирается файл, а не папка).

7. Должна появиться карточка IdleArc Analyst — без ошибок.

ПРОВЕРКА РАБОТЫ

1. Открой https://idlearc.com/app/ и войди в аккаунт.
2. В правом нижнем углу — круглая кнопка с графиком (оверлей).
3. Нажми её: панель покажет характеристики с дельтами.
4. Поиграй, измени что-нибудь в персонаже — появятся новые точки данных.

Если кнопки нет:
- обнови страницу игры;
- проверь, что расширение включено в browser://extensions;
- открой карточку расширения и посмотри текст ошибки (пришли мне).

ЧТО СДЕЛАНО ДЛЯ ANDROID

- ни одного подкаталога: скрипты и иконки в корне;
- из манифеста убраны default_locale и minimum_chrome_version;
- добавлен резервный запуск через chrome.scripting: если браузер не запустит
  обычные content-скрипты (известная проблема мобильной версии), service worker
  внедрит их сам при открытии страницы игры;
- OTA-файлы (ota-config.js, ota-core.js, ota-updater.js, ota.html, ota.css,
  ota.js, options.js) ТОЖЕ лежат в корне. Не переноси их в подпапку;
- файл update.json в корне — это встроенная копия канала на случай, когда
  GitHub недоступен (применяется кнопкой «Встроенный канал (офлайн)»).

ОБНОВЛЕНИЯ ПО ВОЗДУХУ (OTA) — ГЛАВНОЕ

Раньше любую правку приходилось вносить в файлы и заново загружать
распакованное расширение. Теперь это не нужно:

1. В попапе нажми кнопку «OTA» в шапке (или в настройках «Центр обновлений»).
2. Вкладка «Быстрые правки» — меняй лимиты, регулярки, заголовок оверлея,
   объявление игрокам и жми «Применить локально». Сработает сразу.
3. Вкладка «Редактор JSON» — полный документ канала: проверить, скачать
   update.json, скопировать или опубликовать прямо в репозиторий GitHub.
4. Вкладка «Канал» — адрес файла, интервал проверки, публичный ключ подписи.
5. Вкладка «Журнал» — что именно происходило при проверке и почему не применилось.

Расширение само проверяет канал раз в час, при старте браузера и при каждом
открытии страницы игры. На Android системные будильники (alarms) часто не
срабатывают, поэтому проверка дополнительно привязана к открытию игры.

ЕСЛИ ИНТЕРНЕТА НЕТ ИЛИ GITHUB НЕДОСТУПЕН

- Скачай update.json на компьютере (кнопка «Скачать update.json»),
  перенеси на телефон;
- в центре обновлений «Импорт update.json с устройства» — выбери файл;
- либо «Встроенный канал (офлайн)» — он уже лежит в архиве с расширением.

Произвольный адрес канала требует разрешения браузера на доступ к сайту;
на мобильном Яндекс.Браузере такой запрос может быть недоступен — используй
встроенные хосты (raw.githubusercontent.com, gist, *.github.io) или импорт файла.

Полный интерфейс (вкладки «Формулы», «Справочник», «Данные», экспорт) удобнее
на компьютере — там используй обычную сборку release/idlearc-analyst.zip.
Подробное описание формата канала, подписи и инструментов — в README.md.
