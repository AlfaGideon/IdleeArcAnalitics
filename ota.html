Что можно поменять прямо здесь

Изменения сохраняются как локальная правка: она применяется поверх канала мгновенно, без публикации и без перезагрузки страницы игры. Чтобы разослать её на все устройства — открой «Редактор JSON» и опубликуй документ.

Управление применённым

Импорт нужен на Android и в сетях, где GitHub недоступен: положи файл канала в папку с расширением или выбери его здесь — правки применятся без интернета.

Документ канала / локальная правка

Это обычный update.json. Поля settings меняют поведение, patch — подписи, синонимы, CSS и (при подписи) код перехватчика. Незаданные поля не перезаписывают канал.

Шпаргалка по полям

{
  "version": "1.1.1",                 // обязательно, x.y.z
  "changelog": ["что изменилось"],
  "announcement": {"level":"info","text":"сообщение"},
  "settings": {
    "background": {"snapshotMinGapSec":60, "configTtlHours":6},
    "capture": {"limitPerMinute":400, "relevantPattern":"...", "extraApiPaths":[]},

    "metrics": {"strength": {"label":"Сила (новая)"}},

    "overlayCss": ".ia-fab{border-radius:50%}",
    "features": {"pause_capture":false, "sample_all":false},
    "hookCode": null                  // только из подписанного канала!
  }
}

Откуда качать правки

Где разместить файл

  1. Проще всего: этот репозиторий — файл ota/update.json, URL . Публикуй прямо из расширения на вкладке «Публикация».
  2. GitHub Pages / gist / свой сервер: положи update.json и вставь прямую HTTPS-ссылку. Хост должен отдавать Access-Control-Allow-Origin: *.
  3. Без интернета: «Скачать update.json» → перенести на устройство → «Импорт с устройства».

raw.githubusercontent.com кеширует ответы примерно на 5 минут — кнопка «Проверить сейчас» добавляет к URL случайный параметр и получает свежую версию.

Произвольный адрес потребует разрешение на доступ к сайту: браузер спросит его при сохранении. На Android/Yandex такой запрос может быть недоступен — используй встроенные хосты (GitHub, gist, github.io) или импорт файла.

Публикация прямо из расширения

Расширение запишет update.json в репозиторий через GitHub API и сразу подхватит его. Нужен personal access token с правом Contents: read & write только для этого репозитория (fine-grained token).

Токен и приватный ключ хранятся только в chrome.storage.local этого браузера, не попадают в журнал и не экспортируются. Не встраивайте ключ в публичную сборку расширения — для командной работы используйте tools/build-ota.mjs и секрет GitHub Actions.

Подпись канала

node tools/keygen.mjs создаёт пару ключей. Публичный ключ вставь в поле «Публичный ключ» на вкладке «Канал» (или в ota-config.js), приватный — сюда. Тогда документ подписывается при публикации, и расширение отвергнет любую подмену.

Без подписи канал тоже работает: проверяется SHA-256 канонического JSON, а произвольный удалённый hookCode по умолчанию отключается политикой безопасности.
